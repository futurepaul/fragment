# welcome to your notes

This folder is a fragment. Everything here is live: save a change with
`fragment sync --watch` running, and open pages refresh themselves.

Try a [[wikilink]] — it resolves by file name anywhere in the tree. Broken
ones look [[like this]] and stay red until the page exists.

## what renders

- markdown pages (this one)
- code files with syntax highlighting (`app.mjs` in the root, for example)
- images inline, everything else as a download

## conventions

- `_index.md` or `README.md` in a folder becomes that folder's landing page
- frontmatter (`---` block at the top) is stripped, not rendered
