    Send it webhooks

    Anything that sends a webhook can post to this fragment's inbox: fragment open <name> prints its URL (with its token, an editor's).

    • GitHub: the repository's Settings, Webhooks, Add webhook. That URL, content type application/json, and the events Workflow runs and Deployment statuses.
    • Stripe: Developers, Webhooks, Add endpoint, that URL.
    • Anything else: {"source": "deploys", "payload": {"name": "web", "status": "ok", "detail": "v1.2"}}. Sent again with the same id in its payload, an event is updated, not doubled.
